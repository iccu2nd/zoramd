Response

Cara bot membaca pesan dan menampilkan status di WhatsApp.

Auto read Tandai chat sebagai sudah dibaca saat pesan masuk. Default: OFF.
Typing indicator Tampilkan “sedang mengetik…” saat command diproses. Default: OFF.
Fast response Pakai jalur concurrency premium (antrian lebih longgar). Default: OFF.
No prefix Izinkan command tanpa awalan . / # !. Default: OFF.
Error report Kirim log error plugin ke nomor owner. Default: ON.

Access

Premium bypass gconly User premium bot tetap bisa chat pribadi meski gconly ON. Default: OFF.
